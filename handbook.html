Part II

NVIDIA, decoded

Don't think "graphics card company." Think: GPU hardware × CUDA software ecosystem × developers × enterprise applications = the actual NVIDIA moat.

Core NVIDIA terms 10 terms▸
GPU
Graphics Processing Unit — built for massive parallel computation, which happens to be exactly what AI training and inference need.
CPU vs GPU
CPU: fewer, more powerful general-purpose workers. GPU: a huge number of parallel workers. Simplified, but enough to reason with.
AI Training
Teaching a model using data — the expensive, compute-heavy part of building AI.
AI Inference
Using an already-trained model to actually generate outputs. Different workload profile than training.
CUDA
NVIDIA's parallel computing platform. It's the software layer that turns raw GPUs into a developer ecosystem — a real moat beyond hardware.
CUDA-X
Libraries and tools built on top of CUDA for accelerated workloads. Extends the ecosystem outward.
Blackwell & Vera Rubin
NVIDIA's current and next-gen compute architectures. Any AWS proposal has to support today's hardware and tomorrow's.
NVIDIA AI Enterprise
Enterprise software for deploying and running AI in production — GPUs alone don't make AI usable at a company.
Omniverse
Collaborative 3D, simulation, and digital-twin workflows — AI infrastructure isn't just chatbots.
Riva
NVIDIA's conversational AI / speech tooling — another example of infrastructure becoming a real product.
Part III

AWS, decoded

Core AWS & cloud terms 9 terms▸
AWS
Amazon Web Services — Amazon's cloud business: compute, storage, databases, networking, security, AI/ML, dev tools.
Cloud Computing
Using a provider's infrastructure instead of building and running everything yourself — faster, more scalable, less operational weight.
IaaS / PaaS / SaaS
IaaS = infrastructure. PaaS = a platform to build on. SaaS = ready-to-use software. Three different layers of "as a service."
Compute
The processing resources actually running the workload — for AI, that includes GPUs.
Storage
Where data, models, datasets, logs, and backups live. AI datasets can be enormous, so this matters a lot.
Networking
What connects compute resources. At scale, slow GPU-to-GPU communication kills efficiency — this is as much a networking problem as a hardware one.
Scalability
Can the system go from 100 GPUs to 1,000 to 10,000 without falling over? That's the hyperscale question.
High Availability
Designing for minimal downtime — critical when interruptions are extremely expensive.
Disaster Recovery
The plan for restoring operations after hardware failure, cyberattack, outage, or disaster.
Part IV

Where AWS meets NVIDIA

NVIDIA brings accelerated computing + AI software. AWS brings global cloud infrastructure + enterprise services + security + operations. The bid has to prove exactly where that combination creates real, measurable value — not just state that it does.

Shared vocabulary 6 terms▸
GPU Infrastructure
Everything around the GPU — servers, networking, storage, power, cooling, orchestration, security. The GPU is a component; this is the ecosystem that makes it useful at scale.
AI Infrastructure
The complete technology foundation to build, train, deploy, and scale AI: compute, networking, storage, data, software, security, monitoring.
AI Factory
Data → compute → training → models → inference → applications → business value, running continuously. One of NVIDIA's stated strategic priorities.
Sovereign AI
A country or org's ability to build and run AI while controlling its own infrastructure, data, and governance — one global playbook won't fit every market.
Security, end to end
Infrastructure → network → identity → data → applications → operations. NVIDIA's IP and models are the crown jewels here.
Sustainability
Hyperscale AI eats power. Energy efficiency, cooling, and ESG aren't optional line items — they're part of the pitch.
Part V

The money terms

Not just the CFO's job — everyone should be able to answer "why is this financially justified?" in one breath.

Financial & market terms 7 terms▸
ROI
Return on Investment. Not "can we afford $200M" — "what measurable value does NVIDIA get back for $200M."
CAPEX vs OPEX
CAPEX: money on assets that pay off over time. OPEX: recurring cost of actually running the business.
TCO
Total Cost of Ownership — the full lifetime cost (hardware, energy, maintenance, people, downtime), not just the sticker price.
Payback Period
How long until the investment's benefits cover the initial $200M outlay.
Market Sizing
Top-down: start big (global AI spend) and narrow down. Bottom-up: units × average price. Best practice — do both and triangulate.
TAM / SAM / SOM
TAM: total market. SAM: the slice you can realistically serve. SOM: the slice you actually expect to win.
